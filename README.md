# صرح أكاديمي | Sarh Academy 🎓

منصة تعليمية ذكية ومتطورة متخصصة لطلاب الجامعات المصرية، توفر تجربة تعليمية سلسة، محاضرات تفاعلية، كويزات تقييمية، ولوحة تحكم إدارية شاملة.

---

## 🌟 مميزات المنصة

- 🏛️ **دعم متعدد الجامعات والكليات**: تصفح الجامعات المصرية وكلياتها وموادها بسهولة.
- 📺 **قاعة محاضرات ذكية (Smart Classroom)**: مشغل فيديو متطور يدعم جودات متعددة، تحكم بالسرعة، وملاحظات مباشرة.
- 📝 **نظام اختبارات تفاعلي (Interactive Quizzes)**: كويزات تقييمية فورية بعد كل محاضرة لحساب الدرجات ومتابعة التحصيل الدراسي.
- 📊 **لوحة تحكم إدارية شاملة (Admin Dashboard)**: إدارة الطلاب، المواد، الكليات، الأساتذة، الإشعارات، والمدفوعات.
- 🎨 **تصميم حديث وعصري**: واجهة متجاوبة بالكامل تدعم الوضع الليلي والنهاري (Dark / Light Mode) بأعلى معايير الـ UI/UX.

---

## 🛠️ التقنيات المستخدمة

- **Frontend**: Next.js 16 (App Router), React 19, TypeScript, Vanilla CSS Modules, Zustand, React Query, Lucide Icons.
- **Backend API**: NestJS, TypeScript, Prisma ORM, PostgreSQL, JWT Authentication.
- **Monorepo Management**: Turborepo & PNPM Workspaces.
- **Deployment**: Vercel ready (`vercel.json`), PM2 ready (`ecosystem.config.js`).

---

## 🚀 التشغيل محلياً

```bash
# تثبيت الاعتماديات
pnpm install

# تشغيل بيئة التطوير للواجهة والخادم
pnpm dev
```
